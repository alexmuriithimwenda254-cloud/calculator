GLOWCALC — BEGINNER WEBSITE PROJECT

WHAT IS INCLUDED
- index.html: the page structure and calculator buttons
- style.css: the colours, layout, spacing, and decoration
- script.js: calculator operations, keyboard controls, and theme toggle

HOW TO OPEN IT IN VS CODE
1. Download and extract Decorated_Calculator_Project.zip.
2. Open Visual Studio Code.
3. Choose File > Open Folder.
4. Select the extracted folder named Decorated_Calculator_Project.
5. Open index.html.
6. To run it, double-click index.html in File Explorer, or install the free "Live Server" extension in VS Code, right-click index.html, and choose "Open with Live Server".

HOW TO TEST
- Click the number and operation buttons.
- Try 12 + 5 and press =.
- Try AC to clear and ⌫ to delete the last character.
- Press the moon/sun button to switch themes.
- You can also use your keyboard: numbers, +, -, *, /, Enter, Backspace, and Escape.

NOTE
This is a front-end website project and does not need Python, C++, or a server. The font may use an internet connection; the calculator itself works offline.
